# 产品愿景

> 产品定位与长期愿景

## 愿景声明

成为**研究者最信赖的个人论文工作台**——不是又一个推荐算法黑盒，而是一个可理解、可控制、可审计的学术助手。

## 核心价值主张

| 价值 | 说明 |
|------|------|
| **个人化** | 基于你的真实研究兴趣，而非热门趋势 |
| **可审计** | 每条推荐都有理由，每个权重变化都有记录 |
| **本地主权** | 你的数据只属于你，随时可带走 |
| **渐进增强** | 从简单关键词到语义嵌入，按需升级 |

## 与现有产品的区别

| 特性 | Paper-Glean | 商业产品 |
|------|-------------|----------|
| 数据存储 | 本地文件 | 云端数据库 |
| 推荐可解释性 | 命中条目 + 权重 + 理由 | 黑盒算法 |
| 兴趣演化 | 反馈驱动权重调整 | 静态偏好 |
| 离线可用 | 完全支持 | 需联网 |
| 成本 | 免费 | 订阅制 |
