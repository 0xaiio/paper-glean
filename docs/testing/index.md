## 测试原则

1. **核心逻辑优先**：`glean/core.py` 是纯函数，最易测试，覆盖度最高
2. **IO 边界测试**：文件读写、HTTP 请求使用 mock
3. **幂等性验证**：`fetch` 重复执行应产生相同结果
4. **兼容性验证**：早期数据文件格式应能正确解析

## 已知限制

- 未覆盖 arXiv API 实际调用（依赖外部服务）
- 未覆盖 PDF 下载（依赖外部服务 + 文件系统）
- 未覆盖 agent 层（非确定性，需人工验证）
