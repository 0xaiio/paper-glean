# Web 应用使用指南

> 基于 FastAPI + HTMX + Alpine.js 的本地 Web 界面

## 启动

```powershell
# 安装 Web 依赖
pip install -e ".[web]"

# 启动服务器
python -m glean.web

# 或指定端口
python -m glean.web --port 8080
```

打开浏览器访问 `http://127.0.0.1:8000`（或指定端口）。

## 页面导航

| 页面 | 路径 | 功能 |
|------|------|------|
| **Digest 流** | `/digest` | 浏览论文、筛选、打分 |
| **兴趣画像** | `/profile` | 查看 interests.md 条目与权重 |
| **归档库** | `/archive` | 查看已下载的 PDF 文件 |

## Digest 流页面

### 布局

三栏布局：
- **左侧**：日期导航 + 过滤器（类别、命中类型）
- **中间**：论文卡片流
- **右侧**：选中论文详情 + 操作按钮

### 过滤器

- **日期**：选择查看哪一天的论文
- **类别筛选**：勾选/取消 arXiv 类别（cs.AI, cs.LG 等）
- **命中类型**：
  - ★ 候选（命中兴趣点）
  - 🧐 候选（命中扩展点）
  - 其余（未命中）

### 论文卡片

每张卡片显示：
- 标题（点击展开详情）
- 作者、类别
- 🎯 命中标记（如 `🎯★ consensus, BFT`）
- 当前 ★/🧐 评分

### 键盘快捷键

| 按键 | 功能 |
|------|------|
| `j` / `↓` | 下一张卡片 |
| `k` / `↑` | 上一张卡片 |
| `o` | 打开 arXiv 页面 |
| `d` | 下载 PDF |
| `1-5` | ★ 打分（兴趣度） |
| `Shift+1-5` | 🧐 打分（好奇度） |
| `/` | 聚焦搜索框 |

### 打分流程

1. 用 `j`/`k` 或鼠标选择卡片
2. 按 `1-5` 打 ★ 分，或 `Shift+1-5` 打 🧐 分
3. 打分即时生效，自动同步到：
   - `interests.md`（权重更新）
   - `feedback.jsonl`（审计日志）
   - `arXiv-schedule.md`（digest 表格）

## 兴趣画像页面

可视化展示 `interests.md` 中的内容：
- **兴趣点 ★**：当前重点研究方向
- **扩展点 🧐**：值得关注的延伸领域
- 每个条目显示：标题、关键词、权重（1-10）

## 归档库页面

- 列出 `arXiv/` 目录中的 PDF 文件
- 支持按文件名搜索
- 点击直接打开 PDF
